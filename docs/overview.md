# Обзор платформы

Mazy Platform помогает создавать, валидировать, публиковать и запускать сценарии общения для подключенных ботов. Пользователь работает в web-client: создает проекты, описывает граф сценария, публикует release-версию, подключает бота и выбирает, какую версию сценария бот должен исполнять.

Платформа построена как набор независимых сервисов:

- frontend отправляет HTTP-запросы в gateway;
- gateway принимает внешний трафик, проверяет JWT, прокидывает `x-trace-id` и вызывает backend-сервисы по gRPC;
- domain-сервисы владеют своими моделями и хранилищами;
- RabbitMQ связывает сервисы через integration events;
- observability stack собирает logs и metrics.

## Основные возможности

- регистрация и вход пользователя по паролю;
- вход через external provider;
- настройка пароля для provider-пользователей;
- Email MFA и TOTP MFA;
- управление проектами, схемами пользовательских данных и сценариями;
- валидация черновика сценария;
- публикация release-версии сценария;
- история версий и удаление версий сценария;
- подключение, активация и деактивация ботов;
- переключение версии сценария для конкретного бота;
- получение входящих событий от VK и Telegram через bot-integration;
- отправка email-уведомлений через notification service.

## Транспорт и интеграции

- HTTP JSON API: внешний контракт frontend -> gateway, формируется через gRPC JSON transcoding.
- gRPC: gateway -> backend-сервисы, а также внутренние вызовы между сервисами.
- RabbitMQ: асинхронные события между сервисами.
- PostgreSQL: постоянное хранилище user, scenario metadata и bot metadata.
- MongoDB: хранение scenario graph/runtime данных.
- SMTP/email provider: отправка кодов подтверждения, MFA и reset password.
- VK/Telegram API: polling и отправка сообщений ботами.
