# Архитектура

Раздел описывает backend как набор единиц поставки, общих библиотек и инфраструктурных границ. Детальные сценарии лежат в `docs/flows/*`; здесь важны связи между сервисами, владение данными и точки, где изменение одного компонента ломает другой.

- [services.md](services.md) - кто хранит данные, какие sync/async связи использует и какие события публикует или слушает.
- [libraries.md](libraries.md) - общие контракты и runtime-библиотеки, которые связывают сервисы и frontend.
- [deployment.md](deployment.md) - единицы поставки, dev-compose и сетевые границы.
